# Product Definition — Extly

## Summary
Extly is a real-time intelligence platform for Chrome extension developers. It monitors Chrome extensions daily and sends email alerts when key metrics change.

## Problem Statement
Chrome extension developers are flying blind. Existing tools (like ChromeStats) update monthly, leading to delayed reactions to competitor updates, rating drops, or user growth trends.

## Target Users
- **Primary:** Indie developers making $500–$10K/month from Chrome extensions.
- **Secondary:** Agencies and developers managing extensions for clients.
- **Early Adopters:** Developers active on Indie Hackers, Twitter, and Reddit.

## Key Goals
1. Provide daily updates (not monthly).
2. Real-time alerts for rating drops, new versions, and user milestones.
3. Clean, data-forward dashboard inspired by Mixpanel.

## Scope (V1)
Exactly 10 pages focusing on the core scraper → snapshot → change detection → alert pipeline.

## Non-Goals (V1)
- Google OAuth
- Slack notifications
- Competitor comparison
- Payment processing
- Browser extension
